# تحليل ستايل المونتاج القديم (قناة «الأول»)

المصدر: 3 شورتس من قناة «الأول» (01، 17، 19).
الطريقة: ffprobe + كشف القطعات + لوحة إطارات بكل ثانية + تحليل الصوت.

## 1. الخلاصة
هادو **ماشي مونتاج لقطات (stock footage)**. هادو **Motion Graphics مبرمجة** (Remotion / React):
كل مشهد مبني بعناصر: نصوص، أيقونات، كروت، رسوم بيانية، صور أشخاص مقصوصين، وكل عنصر يدخل بأنيميشن
متزامن مع الكلمة اللي تنقال في الفويس. هذا ستايل "explainer" أصلي — وهو بالضبط اللي يحمي من سياسة
"inauthentic content".

## 2. المواصفات التقنية
| | القيمة |
|---|---|
| المقاس | 1080×1920، 30fps، H.264 + AAC 48kHz stereo |
| الطول | 26.8 – 36 ثانية |
| الصوت | فويس + مزيكا خلفية متواصلة (ما كاين حتى صمت)، mean ≈ ‑17 dB، peak ≈ ‑1.5 dB |
| القطعات الحادة | قليلة جداً (3–8 في الفيديو) — المشاهد تتبدّل بانتقالات ناعمة (fade / blur / flash) |

## 3. الهوية البصرية
- **الخلفية:** أزرق ليلي غامق (navy) + شبكة (grid) خفيفة + نقاط ذهبية طايرة (particles) + توهّج ذهبي في الأسفل.
  في بعض المشاهد: أشعة (sunburst) من الوسط.
- **الألوان:** ذهبي/أصفر (#F2B233 تقريباً) للتأكيد + أبيض للنص العادي + أحمر للسلبي (منحنى النسيان، ❌).
- **النص في الأعلى (~15% من الارتفاع):** جملة قصيرة 2–6 كلمات، خط عريض، **الكلمة المفتاحية بالذهبي** مع glow.
  النص يتبني **كلمة بكلمة** مع الفويس (typewriter على مستوى الكلمة)، والكلمة القديمة تتمسح بـ blur كي تتبدّل الجملة.
- **وسط الشاشة:** "الفكرة البصرية" — أيقونة دائرية ذهبية، كروت زجاجية ذهبية (glassmorphism)، رسم بياني، عدّاد رقمي
  (0 → 317)، أشخاص مقصوصين بلا خلفية، شارات (badges/pills) بيضاء.
- **الاستشهاد:** صورة العالِم في كارت + اسم + مرجع الدراسة (Cepeda et al. 2006) + credit الصورة (Wikimedia CC) أسفل الشاشة.

## 4. الحركة
- العناصر تدخل بـ **spring / pop‑in** (scale من 0.8 → 1 مع overshoot خفيف) + fade.
- **رسم تدريجي:** المنحنيات والطرق والأسهم تترسم سطر بسطر (path drawing).
- **عدّادات** تطلع من 0 للرقم.
- **إبراز:** الكارت المهم يكبر ويضوي، الباقي يطفى (dim).
- **انتقال بين المشاهد:** blur‑out للنص القديم + flash أبيض خفيف أحياناً + خط نقاط ذهبي يقود العين للمشهد الجاي.
- **علامات ✓** تطلع على العناصر واحد واحد (list reveal).

## 5. بنية السكريبت (نفس القالب في الثلاثة)
1. **Hook (0–3 ث):** سؤال ولا ادعاء صادم ("واش تعرف بلّي أغلب واش تقراه اليوم… مخّك يبدا يمسحو").
2. **المشكل** مع تسمية علمية ("هذا اسمو منحنى النسيان") + مرجع حقيقي (Ebbinghaus 1885).
3. **الحل** مع دليل (دراسة، رقم، مقارنة بصرية قبل/بعد).
4. **التطبيق:** خطوات عملية ("من غدوة، من بعد أسبوع، من بعد شهر").
5. **Outro ثابت (~4–5 ث):** اللوغو يتبني بالجزيئات + slogan + زر "تابع" + اسم الموقع.

## 6. واش نقلو للقناة الإنجليزية
| نحتفظو بـ | نبدّلو |
|---|---|
| Navy + Gold — يناسب **المال والمليارديرات** أكثر من الدراسة | النص RTL عربي → **LTR إنجليزي**، خط إنجليزي عريض (Montserrat / Inter Black) |
| النص كلمة بكلمة + الكلمة المفتاحية بالذهبي | لوغو واسم القناة الجديدة في الـ outro |
| أيقونات + كروت زجاجية + رسوم بيانية + عدّادات | المحتوى: أسهم، ثروة، شركات، أرقام ($0 salary، 2008…) |
| كارت الاستشهاد بصورة + مصدر + credit | صور المليارديرات: **فقط صور برخصة حرة (Wikimedia CC) مع credit** — كيما كان يتدار |
| قالب Hook → مشكل → دليل → تطبيق → outro | |
