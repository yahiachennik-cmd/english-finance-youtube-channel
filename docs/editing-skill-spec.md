# Editing Skill — Spec (مسودة)

يتعمّر بعد ما يحيى يحدد الخيارات. القيم بين [ ] هي اقتراحات افتراضية.

| البند | القرار |
|---|---|
| المدخل | ملف فويس (mp3/wav/m4a) + سكريبت نصي |
| مصدر الصور واللقطات | ؟ [Pexels/Pixabay API — مجاني وقانوني] أو صور AI أو ملفات يبعثها يحيى |
| ستايل الكابشنز | ؟ [كلمة-كلمة / 2–3 كلمات، خط عريض، الكلمة الحالية ملوّنة، وسط الشاشة] |
| الحركة والزوم | ؟ [Ken Burns zoom خفيف على كل صورة، تقطيع كل 2–3 ثواني] |
| المزيكا والمؤثرات | ؟ [مزيكا خلفية منخفضة + whoosh في الانتقالات] — يلزم مصدر بلا حقوق |
| الإخراج | ؟ [MP4 جاهز 1080x1920، 30fps] أو مشروع للتعديل |
| التعرف على الكلام | Whisper (word timestamps) |
